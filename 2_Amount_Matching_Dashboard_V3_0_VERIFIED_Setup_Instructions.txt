AMOUNT MATCHING DASHBOARD V3.0

Purpose:
Reconcile negative balances by finding combinations of available amounts.

Column A:
Available amounts.

Column B:
Negative amounts to resolve.

Settings:
Variance allowance is adjustable. Default is 150000.

Output:
Target
Match Found
Matched Total
Variance
Quality

Installation:
1. Open Excel.
2. Save as Excel Macro-Enabled Workbook (*.xlsm).
3. Open VBA Editor.
4. Insert Module.
5. Paste VBA code.
6. Run SetupMatchingDashboard.
